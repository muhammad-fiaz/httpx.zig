License: MIT
Built with bun (esbuild IIFE):
  bun build entry.js --outdir=out --minify --target browser --format iife
  cp out/entry.js graphiql.js   (bun names the output after entry.js)
  bun build node_modules/monaco-editor/esm/vs/editor/editor.worker.js --outfile=editor.worker.js --minify --target browser
  bun build node_modules/monaco-editor/esm/vs/language/json/json.worker.js --outfile=json.worker.js --minify --target browser
Files vendored:
- graphiql.js (IIFE bundle; sets window.renderGraphiQL(element, options) where options are
  { endpoint, defaultQuery?, editorTheme?, headers? }; headers is a JSON object merged over
  Content-Type: application/json for every request)
- graphiql.css (bundle CSS; no Monaco fonts inline)
- codicon-mxdk0fnd.ttf (Monaco icon font referenced by graphiql.css)
- editor.worker.js (Monaco editor worker)
- json.worker.js (Monaco JSON language worker)
Notes:
- graphiql 6 no longer depends on monaco-graphql, so graphql.worker.js was dropped.
- Monaco resolves worker scripts relative to document.baseURI; the served page pins <base>
  to the GraphiQL route so the workers load from the mounted asset paths.
Rebuild: install graphiql/react/react-dom/graphql with bun, then run the three bun commands above.
