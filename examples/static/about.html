About httpx.zig

httpx.zig is a modern, high-performance HTTP library for Zig.

Features

  • HTTP/1.0, HTTP/1.1, HTTP/2, HTTP/3 client and server
  • TLS 1.2 and 1.3 with ALPN
  • Connection pooling and keep-alive
  • Pattern-based routing
  • Middleware stack (CORS, auth, rate limiting, etc.)
  • Static file serving with ETag
  • WebSocket and SSE support
  • Multipart form data
